## Spacing Scale

8-point scale — matches the established Gilded Reserve layout. All values multiples of 4.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gaps (`gap-1`), badge padding (`px-2 py-1`) |
| sm | 8px | Row internal gaps (`gap-2`), list rhythm (`space-y-2`), status-badge padding |
| md | 16px | Default section gaps (`space-y-4`), card internal gaps, toolbar padding (`p-4`) |
| lg | 24px | Card/dialog padding (`p-6`), `space-y-6` page rhythm |
| xl | 32px | Page padding (`p-8`), major layout gaps (`space-y-8`) |
| 2xl | 48px | Page-level section breaks, review-dialog max-height gutter |
| 3xl | 64px | Reserved — large empty-state spacing |

Exceptions: icon-only touch targets at 32×32px (`h-8 w-8`) per existing pattern (refresh ghost button); reject-reason input full width of the dialog action row (BidderKycReview pattern, no fixed height — single-line input, `h-10` + `py-2`). No 44px exceptions — desktop dashboard, existing buttons are 40–48px tall. Half-step utilities (`gap-1.5`, `py-0.5`, `h-1.5`, etc.) are forbidden — all spacing multiples of 4.

## Typography

Exactly 4 sizes, exactly 2 weights. Syne `font-black` (800) for everything emphatic; DM Sans regular (400) for body. Line heights: body 1.5, headings 1.2. Inherited from the approved Phase 8 contract.

| Role | Size | Weight | Line Height | Font / Style |
|------|------|--------|-------------|--------------|
| Micro label | 10px | 800 | 1.2 | Syne — `uppercase tracking-widest` (eyebrows, dialog section labels, tab labels, review readout) |
| Body | 14px | 400 | 1.5 | DM Sans — descriptions, list rows, dialog content, empty-state body |
| Heading | 18px | 800 | 1.2 | Syne — dialog title `text-lg`, row name emphasis |
| Display | 24px | 400→800 | 1.2 | Syne — page title `text-2xl font-black uppercase tracking-tight` with gold accent word |

Notes (locked):
- **Micro label is the canonical Gilded Reserve label voice** — `text-[10px] font-black uppercase tracking-widest`, muted `#6B655C` (eyebrows) or gold (emphasis). Do not add new 9px/11px labels.
- Body text never below 14px for readable content; secondary body `#999186`.
- Review dialog eyebrows ("ID Document", "Personal Info") at 10px 800 gold, `uppercase tracking-wider` (BidderKycReview pattern, 10px not 12px).
- Legacy `font-bold` (700) exists in older components — not part of this contract; use 400/800 only.

## Color

Gilded Reserve token set (`globals.css`). 60/30/10 split:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0A0F` (`--bg-deep`) | Page background |
| Secondary (30%) | `#14141B` (`--bg-surface`) + `#1C1C26` (`--bg-elevated`) | List rows, dialogs, tab pills (inactive), input backgrounds |
| Accent (10%) | `#C9A05C` (`--gold`) | Reserved-for list below |
| Destructive | `#D44545` (`--red`) | Reject action, REJECTED badge — destructive actions only |
| Success (semantic) | `#3DA86C` (`--green`) | VERIFIED badge, empty-state icon, success toasts |
| Warning (semantic) | `#D4A84B` (`--amber`) | Reserved — no primary use this phase; do not use for PENDING (use gold per below) |

**Accent (#C9A05C) is reserved for:**
1. Page-title accent word ("…KYC Review")
2. PENDING status badge (`rgba(201,160,92,0.1)` bg + gold text + Clock icon)
3. Verify (approve) CTA background (`background: var(--gold)`, text `#0A0A0F`) — the primary action
4. Refresh ghost button (gold border/text), active tab pill indicator (`bg-[#C9A05C] text-[#0A0A0F]`), row icon tints
5. Signed-document link text (`text-[#C9A05C] hover:underline` + ExternalLink icon)
6. Focus rings (`focus:border-[#C9A05C] focus:ring-2 focus:ring-[rgba(201,160,92,0.2)]`)

**NOT for:** body/table chrome text, borders (borders stay `rgba(201,160,92,0.08/0.15/0.25)`), background fills of large surfaces.

Borders: `--border-subtle` `rgba(201,160,92,0.08)` (row cards), `--border` `0.15` (dialog, inputs), `--border-strong` `0.25`. Card surface gradient (canonical): `linear-gradient(160deg, #1C1C26 0%, #14141B 100%)` + 1px gold border. Modal backdrop: `bg-black/60 backdrop-blur-sm`; dialog surface `#14141B` with `border: 1px solid rgba(201,160,92,0.15)` (BidderKycReview pattern). REJECTED action styling stays red (`bg-red-600 hover:bg-red-500` CTA, or red-ghost per row pattern).

KYC status badge palette (4 states — used in both SalesPos badge and review-screen row icons):

## Copywriting Contract

| Element | Copy |
|---------|------|
| Page title | **"Customer KYC Review"** — accent word "KYC"; subtitle (micro label): "Verify client identity records before pawn ticket creation and disbursement" |
| Primary CTA (per pending row) | **"Verify"** — direct action on click (BidderKycReview pattern, no Swal gate); success toast "KYC marked as verified." |
| Reject action | **"Reject"** — inline required reason input in the dialog action row; button disabled until reason non-empty; success toast "KYC submission rejected." |
| Empty state (Pending tab) | Heading: **"No pending KYC submissions"** — Body: "New customer KYC captures will appear here for verification." |
| Empty state (All tab) | Heading: **"No KYC records found"** — Body: "Records appear once staff capture a customer's identity details at the counter." |
| Error state (fetch) | **"Failed to load KYC records"** + "Check your connection and try again." — inline error card with Retry button + `showToast(error.message, 'error')` |
| Gate-block toast (ticket creation) | **"KYC required — this customer is not verified. Capture and complete KYC verification before creating a pawn ticket."** — surfaced from the backend 409 via `showToast(err.message, 'error')` in SalesPos |
| Gate-block toast (approve / disburse) | Backend 409 message surfaced via `showToast(err.message, 'error')` in the approval / loan-disbursement flows — pattern: "Loan disbursement is blocked until the client's KYC status is VERIFIED." |
| Review readout (already decided) | **"Verified on {formatDate(reviewedAt)}"** / **"Rejected — {rejectionReason} on {formatDate(reviewedAt)}"** — muted micro-label + semantic color, BidderKycReview pattern |
| Destructive confirmation | Reject is the only destructive action. Gate = required rejection reason + explicit **"Reject"** button (no double-confirm; the mandatory comment IS the confirmation gate — BidderKycReview pattern). |

Notes (locked):
- **Short CTA labels are intentional.** "Verify" and "Reject" are single-word labels by design (inherited BidderKycReview pattern, approved Phase 8 contract). The row/dialog context supplies the grammatical object — each list row represents one named customer's KYC submission, and the dialog action row sits directly beneath that customer's name and ID readout. Do not expand the labels to "Verify Submission" / "Reject Submission" — short labels are locked.

## Page Structure (CustomerKycReview — top to bottom)

1. **Header row** — `flex items-center justify-between`: left = Display title block (h1 "Customer KYC Review" with gold "KYC" + micro-label subtitle); right = Pending tab pill with live count (`bg-[#C9A05C] text-[#0A0A0F]` when active) + All pill (`bg-[#1C1C26] text-[#9B9488] hover:text-[#EAE2D6]` when inactive) + Refresh ghost button (gold border/text, Loader2 spin while loading). Pills carry the canonical 10px micro-label voice (`text-[10px] font-black uppercase tracking-widest rounded-lg px-3 py-2`) — custom pill buttons, not shadcn Tabs (BidderKycReview layout).
2. **List** — card-style rows (`space-y-2`), each row (`p-4 rounded-xl bg-[#1C1C26] border border-[rgba(201,160,92,0.08)] hover:border-[rgba(201,160,92,0.2)] cursor-pointer`): status icon tile (`p-2 rounded-lg` + state palette), fullName (`text-sm font-normal text-[#EAE2D6]`, 1-line truncate) + meta (`text-[10px] text-[#9B9488]`: contactNumber · idType · Submitted {formatDate(createdAt)}), Eye affordance (right). Click opens review dialog.
3. **Loading** — centered muted text "Loading KYC records..." (`py-12 text-[#9B9488]`), BidderKycReview pattern.
4. **Error** — inline error card (`bg-red-500/5 border-red-500/20`) with the error copy + Retry button.
5. **Empty** — centered block (`py-12 text-[#9B9488]`): Shield icon (`w-12 h-12 mx-auto mb-3 opacity-30`), per-tab empty copy (heading + body, see Copywriting).
6. **Review dialog** — fixed overlay (`bg-black/60 backdrop-blur-sm`), surface `bg-[#14141C] border border-[rgba(201,160,92,0.15)] rounded-2xl max-w-4xl w-full max-h-[90vh] overflow-y-auto p-6`. Header: name (`text-lg font-black text-[#EAE2D6]`) + sub (`{idType} #{idNumber}`, muted) + close ×. Body: `grid grid-cols-2 gap-6` — left "ID DOCUMENT" (gold micro-label eyebrow) with 2-3 signed-URL links (View ID Front / View ID Back / View Selfie — gold, ExternalLink icon); right "PERSONAL INFO" with contactNumber, address, captured/submitted date. PENDING → action row (`flex items-end gap-3`): **[Verify]** gold CTA (`px-4 py-2 bg-[#C9A05C] ... text-[#0A0A0F]`, CheckCircle icon) + rejection-reason `ui/Input` (`bg-[#1C1C26] border border-[rgba(201,160,92,0.15)]`, placeholder "Rejection reason (required to reject)") + **[Reject]** red CTA (`bg-red-600 hover:bg-red-500`, XCircle icon, disabled until reason non-empty) — exact BidderKycReview action row. Reviewed → readout (verified/rejected + reason + date, semantic color). `actionLoading` disables both CTAs and swaps for Loader2.
7. **Per-row processing lock** — `actionLoading` disables the dialog CTAs (BidderKycReview pattern); the list reloads after each decision (`await load()`).

**SalesPos KYC surface** — `KycStatusBadge` rendered inline next to the "Customer" field label in the customer section (`space-y-4` between name/contact/address inputs). Badge resolves the current customer's `kycStatus` from a lightweight lookup (`GET /kyc/customers` search by name/contact — exact query shape is plan-phase discretion per D-04); shows the 4-state pill (`px-2 py-1 rounded-lg text-[10px] font-black uppercase tracking-widest` + state palette). When a 409 returns on ticket creation, the backend message surfaces via error toast; the form stays open with entered values (no reset).
