## Interface Contract (locked for downstream plans)

The following API surface is fixed by this plan's RED specs; plans 08-02/08-03 implement against it without changing it:

- `ApprovalService.getQueue(query: ApprovalQueueQueryDto, callerPawnshopId: string): Promise<ApprovalQueueItem[]>`

- `POST /approval-queue/:id/approve` — @RequiresPermission(PERMISSIONS['approval.approve_appraisal'])
- `POST /approval-queue/:id/reject` — @RequiresPermission(PERMISSIONS['approval.approve_appraisal'])

- Frontend: `api.get<ApprovalQueueItem[]>('/approval-queue', { pawnshopId, type })`, `api.post('/approval-queue/:id/approve', { decisionComment })`, `api.post('/approval-queue/:id/reject', { decisionComment })`
