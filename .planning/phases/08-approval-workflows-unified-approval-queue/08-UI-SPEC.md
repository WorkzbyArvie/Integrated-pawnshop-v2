## Spacing Scale

8-point scale — matches the established Gilded Reserve layout. All values multiples of 4.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gaps inside buttons (`gap-1.5`), badge padding (`px-2 py-0.5`) |
| sm | 8px | Compact element spacing (`space-y-2`), row internal gaps, table cell padding |
| md | 16px | Default section gaps (`space-y-4`), card internal gaps, toolbar padding (`p-4`) |
| lg | 24px | Card padding (`p-6`), dialog padding, `space-y-6` page rhythm |
| xl | 32px | Page padding (`p-8`), major layout gaps (`space-y-8`), dialog `max-w-lg` gutter |
| 2xl | 48px | Page-level section breaks, detail panel spacing |
| 3xl | 64px | Reserved — large empty-state spacing (`py-20` equivalent pattern) |

Exceptions: icon-only touch targets (photo-nav chevrons in review dialog) at 32×32px (`h-8 w-8`) per existing pattern; reject-reason textarea fixed height 96px (`h-24`). No 44px exceptions — this is a desktop dashboard, existing buttons are 40–48px tall (`py-3`/`py-4` + text).

## Typography

Exactly 4 sizes, exactly 2 weights. Syne `font-black` (800) for everything emphatic; DM Sans regular (400) for body. Line heights: body 1.5, headings 1.2.

| Role | Size | Weight | Line Height | Font / Style |
|------|------|--------|-------------|--------------|
| Micro label | 10px | 800 | 1.2 | Syne — `uppercase tracking-widest` (card eyebrows, table headers, button labels, tab labels) |
| Body | 14px | 400 | 1.5 | DM Sans — descriptions, table cells, dialog content, empty-state body |
| Heading | 18px | 800 | 1.2 | Syne — card titles (`text-lg`), dialog titles, amount emphasis |
| Display | 24px | 400→800 | 1.2 | Syne — page title `text-2xl font-black uppercase tracking-tight` with gold accent word |

Notes (locked):
- **Micro label is the canonical Gilded Reserve label voice** — `text-[10px] font-black uppercase tracking-widest`, muted `#6B655C` (eyebrows) or gold (emphasis). Existing components also use 9px; the contract pins 10px — do not add new 9px/11px.
- Body text never below 14px for readable content; secondary body `#999186`.
- Amounts (appraised value, amountPaid) render at **18px Syne 800 gold** (`text-lg font-black` + `var(--gold)`), matching existing valuation displays.
- Legacy `font-bold` (700) exists in older components — not part of this contract; use 400/800 only.

## Color

Gilded Reserve token set (`globals.css`). 60/30/10 split:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0A0F` (`--bg-deep`) | Page background |
| Secondary (30%) | `#14141B` (`--bg-surface`) + `#1C1C26` (`--bg-elevated`) | Queue rows, cards, dialogs, input backgrounds, table rows |
| Accent (10%) | `#C9A05C` (`--gold`) | Reserved-for list below |
| Destructive | `#D44545` (`--red`) | Reject actions, REJECTED badge, reject-dialog border/icon — destructive actions only |
| Success (semantic) | `#3DA86C` (`--green`) | APPROVED badge, "All caught up!" icon, success toasts |
| Warning (semantic) | `#D4A84B` (`--amber`) | High-risk flag, above-threshold indicator |

**Accent (#C9A05C) is reserved for:**
1. Page-title accent word ("…Queue")
2. PENDING status badge (`rgba(201,160,92,0.1)` bg + gold text)
3. Money values — appraised value / recommended loan / amountPaid
4. Primary Approve CTA background (`background: var(--gold)`, text `#030213`)
5. Refresh ghost button (gold border/text), active tab indicator, Loader2 spinners, row icon tints
6. Focus rings (`focus:border-[#C9A05C] focus:ring-2 focus:ring-[rgba(201,160,92,0.2)]`)

**NOT for:** body/table chrome text, borders (borders stay `rgba(201,160,92,0.08/0.15/0.25)`), background fills of large surfaces.

Borders: `--border-subtle` `rgba(201,160,92,0.08)`, `--border` `0.15`, `--border-strong` `0.25`. Card surface gradient (canonical): `linear-gradient(160deg, #1C1C26 0%, #14141B 100%)` + 1px gold border. Modal/dialog backdrop: `bg-black/70 backdrop-blur-sm`, dialog surface `#14141B` with `border: 1px solid rgba(201,160,92,0.15)` (reject dialog uses red border `rgba(212,69,69,0.2)` per existing pattern).

## Page Structure (ApprovalQueue — top to bottom)

1. **Header row** — `flex items-center justify-between`: left = Display title block (h1 + micro-label subtitle); right = pending-count pill (`bg-[#14141B]` card, "Pending" micro label + gold 24px count, per `AppraisalApproval` pattern) + Refresh ghost button (gold border/text, Loader2 spin while loading).
2. **Tabs row** — shadcn `Tabs`: `Appraisal` (gold Badge count) | `Redemption` (gold Badge count) | `Decision History`. Tab list styled with the micro-label voice; active tab gold.
3. **Toolbar** — search input (Search icon left, placeholder "Search by customer name or ticket number…", gold focus ring, `#EAE2D6` text) + threshold note (redemption tab only, muted micro-label).
4. **Queue list** — card-style rows (`space-y-4`), each row: type badge (APPRAISAL/REDEMPTION), ticket number (gold micro-label), customer name + loyalty tier badge (existing `tierColors` map), item summary (category — weight), amount (gold 18px), requestedBy + submitted date (`formatDateTime`), per-row actions **[Review] [Approve] [Reject]** (Review ghost, Approve gold, Reject red-ghost — exact styling from `PendingApprovalPanel`).
5. **Loading** — 3 `Skeleton` rows; **error** — inline error card + Retry; **empty** — per-tab empty copy (CheckCircle2 green / CheckCheck icon pattern).
6. **Review dialog** — `ui/Dialog`, `max-w-lg`, `#14141B` surface. Appraisal: photo gallery (chevron nav, existing pattern), customer/item detail rows (existing label/value `rgba(255,255,255,0.035)` row style), valuation block (`bg-[#C9A05C]/10` with gold amount + risk flag), appraisalNotes, previous rejection comment (amber-bordered callout if present). Redemption: ticket detail rows + amountPaid + threshold comparison.
7. **Reject dialog** — `ui/Dialog` with red border, AlertTriangle icon, required Textarea, "Cancel" / "Confirm Reject" (red `#D44545`, disabled until non-empty).
8. **ContractViewer mount** — appraisal approve → advance → open contract signing → `onSignComplete` → Disburse (existing flow reused verbatim).
9. **Decision History tab** — `ui/Table` (wrapped in `ScrollArea`/`overflow-x-auto`), newest first, columns: Decision (Badge APPROVED green / REJECTED red / CANCELLED muted), Type, Reference, Amount, Approver, Comment (truncate), Decided At. Full history per D-10 discretion.

**Per-row processing lock:** `processingId` disables that row's buttons and swaps the label for a gold Loader2 (existing pattern). Self-approval prevention (requester cannot approve own request) — hide/disable Approve with muted copy if straightforward to implement (discretion).
