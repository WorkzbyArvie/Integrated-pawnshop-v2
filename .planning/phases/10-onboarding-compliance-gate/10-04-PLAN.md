# 10-04 — ONB-02/03/04: Review modal view-before-approve + owner dashboard status banner (frontend)

> Wave 4 (frontend, depends on the backend API contract from 10-01..10-03). The final vertical slice: the SUPER_ADMIN review modal enforces view-before-approve against the new view endpoint, and the owner PendingAccessDashboard shows the aggregated REJECTED/ACTION_REQUIRED status live.

## Objective

Wire both UI surfaces to the Phase 10 backend (all endpoints live after 10-03):

- **TrialRequestsPanel.tsx (SUPER_ADMIN):** D-08 — Approve in the document review modal stays disabled until the document has been *viewed*: the modal-open handler POSTs the view endpoint and adds the doc id to `viewedDocIds`; docs whose server record already has `has_viewed=true` (from `GET .../documents/admin` via 10-02) unlock Approve on reopen. Reject stays always-enabled.
- **PendingAccessDashboard.tsx (OWNER):** D-11 — overall status banner (ACTION_REQUIRED/APPROVED/PENDING_REVIEW/INCOMPLETE) from `GET /me/status`, plus per-state supporting copy using `rejectedDocumentCount`. D-12 — refresh on mount, after upload/submit/cancel, manual Refresh, and a 30s interval (NotificationCenter precedent; no Supabase Realtime).

Pure decision/tone logic lives in a new `frontend/src/lib/onboardingStatus.ts` with a vitest mirror, following the existing `kycDocs.ts`/`kycDocs.test.ts` pattern.

**Purpose:** Close the loop for ONB-02 (view state enforced in the UI *and* server), ONB-03 (REJECTED → ACTION_REQUIRED visible to the owner), ONB-04 (real-time per-document status end-to-end).
**Output:** Two component edits, one new helper module + mirror, typecheck + vitest green.

## Requirements

- **ONB-02** — Admin reviews onboarding documents inside the viewer modal; Approve is disabled until the document is opened/viewed (`hasViewed` persisted server-side).
- **ONB-03** — REJECTED doc → overall REJECTED/ACTION_REQUIRED, reflected in the owner dashboard.
- **ONB-04** — Client Compliance Dashboard reflects real-time per-document approval status end-to-end.
