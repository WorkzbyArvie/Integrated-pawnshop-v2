<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form → NestJS credential routes | Passwords/codes are untrusted input; client validation is guidance only. |
| Authenticated session → AccountSecurityGuard | A UI gate can be bypassed by a direct request; the backend guard remains authoritative. |
| Browser module memory → protected API header | The MFA assertion is bearer-like while held in memory and must be cleared on session boundaries. |
| Dashboard navigation → role/access-state filtering | Role-filtered navigation can accidentally hide or redirect universal security access. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10.1-41 | Information Disclosure | Password/OTP/assertion persisted in browser storage | critical | mitigate | Memory-only component/client state, explicit assertion clear lifecycle, and no-secret component tests; never use the existing draft storage for secret fields. |
| T-10.1-42 | Spoofing | Login challenge rendered as an ordinary dismissible dialog | high | mitigate | Dedicated non-dismissible Radix composition/full-viewport route, focus containment, and no operational content mounted behind it. |
| T-10.1-43 | Tampering | Client marks MFA enabled or disabled without server mutation | high | mitigate | Status badge changes only after the corresponding backend response; enrollment/disable tests assert request sequence and cancellation state. |
| T-10.1-44 | Elevation of Privilege | Role filter hides Account Security for pending/frozen/Super Admin | high | mitigate | Universal route/navigation block independent of operational role filters, with explicit state-matrix tests. |
| T-10.1-45 | Denial of Service | OTP brute force or unbounded resend | high | mitigate | Backend route throttles/challenge lockout from Plan 03 plus 60-second client cooldown and no auto-submit. |
| T-10.1-46 | Information Disclosure | Cross-tenant status/activity rendered in the page | high | mitigate | Use only profile-scoped API responses and server-masked email; never accept a browser target profile id. |
| T-10.1-SC | Tampering | npm/pip/cargo installs | low | accept | No new UI package is installed; existing Tailwind/Radix/Lucide/Testing Library dependencies are reused, so there is no phase install task to audit. |
</threat_model>
