<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dashboard form → NestJS credential route | Passwords/codes are untrusted; client validation is guidance only. |
| Administrative form → tenant/account API | Target ids and temporary passwords require server authorization. |
| Dashboard component state → browser storage | Secret form fields must never cross into persistent storage. |
| Tracked source scan → usage claim | Each named surface must be proven, not inferred from the shared component test. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10.1-41 | Information Disclosure | Password/code/temporary credential persisted in browser storage | critical | mitigate | Narrow drafts to non-secret fields and fail the tracked-source usage test on secret keys/raw forms. |
| T-10.1-42 | Tampering | Active surface retains a local duplicate policy | high | mitigate | Per-surface import/usage matrix requiring PasswordField/PasswordRequirements. |
| T-10.1-43 | Information Disclosure | Temporary password displayed/copied after admin success | high | mitigate | Remove the success artifact and assert no temporary value in rendered output/source. |
| T-10.1-44 | Elevation of Privilege | Administrative target chosen only in client state | high | mitigate | Preserve route-target authorization and server tenant checks from 10.1-04. |
| T-10.1-45 | Information Disclosure | Raw server error body displayed | medium | mitigate | Map approved policy/error copy and never dump response bodies. |
| T-10.1-SC | Tampering | npm/pip/cargo installs | low | accept | No new UI package; existing Tailwind/Radix/Lucide/Vitest dependencies are reused. |
</threat_model>
