## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public login → challenge route | Email input is untrusted and rate-limited. |
| Authenticated client → MFA routes | Current password, code, and challenge id cross the API boundary. |
| Backend service role → challenge/assertion tables | Only backend code sees HMACs, pepper, and raw in-memory codes. |
