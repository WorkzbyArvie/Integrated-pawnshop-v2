## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form → credential routes | Passwords/recovery values are untrusted and must not persist. |
| App shell → server status | Missing/stale status must not be treated as authorization. |
| Account Security UI → API projection | Browser must not choose another profile or render raw secrets. |
