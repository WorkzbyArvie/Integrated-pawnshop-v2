</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/Supabase Data API → credential tables | Anonymous or authenticated clients could bypass NestJS if public-schema grants remain. |
| NestJS service role → PostgreSQL | Backend owns all credential-state, challenge, assertion, and audit writes. |
| Deployment operator → live Supabase project | The pre-existing `security_logs` table and migration order cannot be inferred from git alone. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10.1-01 | Information Disclosure | `credential_states` through public Supabase grants | critical | mitigate | Enable RLS, revoke `anon`/`authenticated`, expose only the profile-scoped security API, and verify privileges at the blocking checkpoint. |
| T-10.1-02 | Information Disclosure | `mfa_email_challenges.code_hash` and assertion hashes | critical | mitigate | Store HMAC/token hashes only, keep both tables browser-revoked, and return no hash or raw code through controllers. |
| T-10.1-03 | Tampering | Legacy backfill re-marks resolved accounts | high | mitigate | Use the profile-state uniqueness plus `WHERE NOT EXISTS`; verify a second migration run leaves resolved rows unchanged. |
| T-10.1-04 | Spoofing | `profiles.password_hash` remains an alternate verifier | high | mitigate | Null physical values in migration A, remove the Prisma/runtime accepting path in the tracer/plan 04, and source-scan runtime auth code. |
| T-10.1-05 | Repudiation | `security_logs` lacks actor/tenant context | high | mitigate | Add nullable actor, target, pawnshop, and safe metadata columns while preserving old rows; downstream services write the complete envelope. |
| T-10.1-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this phase; the Package Legitimacy Audit is explicitly not applicable, and the plan reuses installed Prisma/Nest/Node facilities. |
</threat_model>
