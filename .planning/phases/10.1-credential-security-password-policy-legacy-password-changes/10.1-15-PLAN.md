## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auction form/context → NestJS security routes | Bidder passwords and codes are untrusted input. |
| AuthContext → protected auction services | Header omission or stale assertion can bypass UI intent. |
| Auction pre-Routes → operational content | Client gate is presentation; backend guard remains authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10.1-151 | Spoofing | Protected fetch omits or crosses the session assertion | critical | mitigate | Central authHeaders utility and regression tests over protected helpers. |
| T-10.1-152 | Elevation of Privilege | Auction content renders during forced or MFA state | critical | mitigate | Pre-Routes non-dismissible gates and page tests. |
| T-10.1-153 | Information Disclosure | Cross-profile or raw credential data in auction UI | high | mitigate | Own-profile API projection, masking, and no-secret tests. |
| T-10.1-154 | Tampering | Local-only MFA badge or toggle | high | mitigate | Server request sequence and refetch after confirmed mutation. |
| T-10.1-SC | Tampering | npm/pip/cargo installs | low | accept | No new package; existing React, Supabase, Phosphor, and Vitest facilities are reused. |
</threat_model>
