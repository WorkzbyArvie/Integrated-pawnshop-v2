# 10.1-01 — Credential security tracer: policy, owner signup, forced change, and Account Security

> Wave 2 follows the schema/RLS checkpoint in 10.1-02. This is the phase's first plan and its leading task is the required production-quality tracer. The slice is intentionally owner-centric: the policy and state service are wired for every backend account-creation path, while the first browser path proves the owner experience end to end. Dashboard-wide forms and all MFA interactions expand in later plans.

## <objective>
Deliver the smallest complete credential-security journey that a real user can perform: create an owner account with the shared policy, authenticate, load server-owned credential status, encounter the blocking legacy gate when required, change the password from universal Account Security, and clear the gate only after the backend accepts the verified change.

Purpose: Prove the server-owned contract and the backend-first vertical architecture before layering MFA and cross-client breadth. This plan establishes D-01, D-02, D-03, D-04, D-05, D-06, D-07, D-10, D-11, and D-12 for the first slice.

Output: Shared policy/status/change services and DTOs, Supabase-authoritative login/update behavior, server forced-change enforcement, owner signup guidance, the blocking gate, Account Security password UI, and automated integration/component tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public owner signup form → NestJS auth routes | Untrusted email, password, role, and verification-token input crosses the public API. |
| Authenticated browser → SecurityController/AccountSecurityGuard | A bearer token and client-supplied body must not be trusted to choose another profile or bypass forced state. |
| NestJS → Supabase Auth/Prisma | Supabase owns password verification/write; Prisma owns profile-scoped state/audit data. |
| Browser storage → security UI | A compromised page must not find a password, raw code, or service credential in persistent browser storage. |
